## Philosophy 🏛️

<h3>✺ Craft 🪨</h3>
<p><img src="assets/flint-craft-pixel.png" width="120" alt="A pixel-art flint handaxe beside a hammerstone and flakes"></p>
<p>I explore the alternatives, weigh the tradeoffs, and sweat the details, especially the ones other people will build on.</p>

<h3>✺ Accountability 🧑‍⚖️</h3>
<p><img src="assets/flint-accountability-pixel.png" width="120" alt="Two pixel-art flint stones held together by precisely fitted interlocking edges"></p>
<p>AI writing code is here to stay, but I still own every decision in it. "It's not me, it's the agent" doesn't cut it. I judge the work by what users actually go through, and I take failures seriously.</p>

<h3>✺ Enablement 🔋</h3>
<p><img src="assets/flint-enablement-pixel.png" width="120" alt="A pixel-art flint core yielding a blade, scraper, and arrowhead"></p>
<p>Good software lets you do more without asking permission. That's why I build in the open: code you can read, change, and build on without depending on me.</p>

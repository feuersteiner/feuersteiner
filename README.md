# feuersteiner

Building software with AI. Working across business, product,
design, and engineering.

[Writing & experiments ↗](https://flintworks.dev)

## Philosophy

- **Craft.** Care about the details, especially when other people
  will build on them.
- **Ownership.** Keep tools understandable, adaptable, and open
  to the people using them.
- **Judgment.** Faster building makes choosing what deserves
  to be built more important.
- **Independence.** Good work needs autonomy, focus, and room
  for a life outside it.
